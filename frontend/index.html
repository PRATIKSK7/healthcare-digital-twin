📈 Linear Regression
Baseline OLS model. Learns linear coefficients for each feature. Simple and interpretable but unable to capture non-linear symptom interactions. RMSE 12.48, R² 0.73.
🌲 Random Forest Regressor
Ensemble of 500 decision trees with bootstrap aggregation. Captures non-linear relationships and feature interactions. n_estimators=500, max_depth=12. RMSE 8.94, R² 0.87.
⚡ XGBoost Regressor
Gradient-boosted trees with L1/L2 regularization. learning_rate=0.05, n_estimators=800, max_depth=6, subsample=0.8. Strong generalization on structured tabular data. RMSE 7.31, R² 0.91.
🚀 CatBoost Regressor DEPLOYED
Ordered boosting with symmetric trees and native categorical feature support. iterations=1000, learning_rate=0.03, depth=8, l2_leaf_reg=5. Best generalization with lowest RMSE (6.88) and highest R² (0.92). Deployed for production severity prediction.
